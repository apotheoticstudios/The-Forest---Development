# The Forest Ambience

This is an additive environmental layer for The Forest. It does not replace
textures, biome colors, weather, shaders, music, or the behaviour of any
existing ambience mod.

Current effects:

- Very subtle airborne motes around natural redwood and fir trunks.
- Fainter ground-level motes around moss in damp forest areas.

The matching `the_forest_ambience` data files under `kubejs/data` add sparse
mixed understory pockets to newly generated redwood and coniferous forest
chunks.
